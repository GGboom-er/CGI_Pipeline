# API Help: maya.asset.maya_get_scene_info

- 作用与场景：获取 Maya 当前场景的全面信息，包括对象统计、面数、材质列表、时间轴、渲染器、引用文件、未知节点等。AI 理解场景全貌的基础能力。
- 用法：`execute_api(maya.asset.maya_get_scene_info, params={...})`
- DCC：`maya`；层级：`read`；执行：`background / foreground`

## 参数
- 无专属参数。

## 输出
- 获取 Maya 当前场景的全面信息，包括对象统计、面数、材质列表、时间轴、渲染器、引用文件、未知节点等。AI 理解场景全貌的基础能力。

此文件是渐进式阅读入口；机器契约以同目录 `api.yaml` 为准。
